# SpendWise – Budget Based Product Finder

SpendWise is a web application developed using the MERN Stack that helps users find products according to their budget and preferences. The main objective of this project is to make product searching easier by providing budget-based filtering and personalized recommendations.

## Features

- User Registration and Login
- Secure Authentication
- Browse Products
- Search Products
- Budget-Based Filtering
- Wishlist Management
- User Dashboard
- Admin Panel
- Responsive User Interface

## Installation

### Clone Repository

```bash
git clone https://github.com/itoufique/SpendWise.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```
